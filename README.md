# Waylaid Ledger

## Main features

- Compare the cost of buying and filling **Waylaid Crates** and **Craftsman's
  Writs** in **WoW Forever**, ranked by reputation or Merchant's Favor per gold.
- See crate filling costs in tooltips and browse saved auction prices anywhere.
- Plan and save writ delivery trips with routes, shopping lists, travel estimates
  and estimated coin-pouch rewards.
- Shop through Auctionator or the game's buying screens, with optional
  Auctionator and TradeSkillMaster price data. No other addons are required.
- Use Forever's native controller UI, mouse or keyboard.

## Installation

1. Download **`WaylaidLedger-1.6.1.zip`** from the
   **[latest release](https://github.com/AlphaB/waylaid-ledger/releases/latest)**
   under **Assets**. Choose the addon ZIP, not “Source code”.
2. Close WoW and extract the ZIP.
3. Copy the **`WaylaidLedger`** folder into your Forever client's
   **`Interface/AddOns`** folder. The finished path should be:

   ```text
   World of Warcraft/_forever_/Interface/AddOns/WaylaidLedger/WaylaidLedger.toc
   ```

   Some installations use `_classic_beta_` instead of `_forever_`. Avoid an
   extra nested `WaylaidLedger` folder.
4. Start Forever and enable **Waylaid Ledger** in **AddOns** at character
   selection. Open it with the minimap button or **`/wll`**.

**Updating:** close the game and replace the old `WaylaidLedger` folder.
Leave the game's `WTF` folder untouched to keep your saved prices and settings.
